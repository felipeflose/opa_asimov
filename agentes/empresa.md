## 🏗️ Cultura

### Não-Hierárquica por Design
Na TechFuse, o título não manda — a ideia manda. Um dev júnior pode parar uma feature se tiver um argumento sólido. Uma PM pode ser desafiada por um QA. O que vale é a lógica, os dados e o impacto para o usuário.

### Resultado > Processo
Não medimos horas. Medimos entrega, qualidade e impacto. Se você prefere trabalhar de madrugada ou de manhã cedo, tudo bem — desde que as cerimônias sejam respeitadas.

### Psychological Safety
Errar é parte do processo. O que não toleramos é esconder erro. Bug em produção? Poste no canal `#incidentes` sem vergonha. A gente resolve junto.

### Remote-First, Office-Available
Escritório disponível toda terça e quinta para quem quiser. O resto é remoto. Câmera na Daily é opcional, mas participação é obrigatória.

## 💻 Stack Tecnológico

### Backend
- **Python 3.11+** — linguagem principal
- **Flask** — API REST
- **SQLite** + **ChromaDB** — dados relacionais e vetoriais
- **Ollama** — modelos locais (llama3, mistral)
- **Groq API** — inferência rápida em produção

### Frontend
- **D3.js** — visualização do grafo de conhecimento
