## Tipos de Dados

## Estruturados

Dados organizados em tabelas com esquema definido Ex.: banco de dados relacional, CRM, ERP

## Desafio:

Limitados àquilo que foi previamente definido

<!-- image -->

## Semi-Estruturados

Dados que têm alguma organização (tags, chaves) mas sem esquema fixo rígido Ex.: JSON, XML, logs, dados de IoT

## Desafio:

Integração entre diferentes sistemas

## Não Estruturados

Dados sem esquema pré -definido Ex.: imagens, vídeos, áudios, documentos de texto livre, redes sociais

## Desafio:

Processamento e extração de valor complexos

## O que é aprendizado não supervisionado?

É quando o modelo recebe apenas os dados brutos, sem

rótulos, e tenta descobrir

É quando o modelo recebe apenas os dados brutos, sem rótulos, e tenta descobrir padrões, grupos ou estruturas por conta própria

<!-- image -->

parecidos etc

Ele organiza os dados em clusters, associações ou dimensões escondidas, ajudando a revelar segmentos de clientes, comportamentos parecidos etc

Não supervisionado = descobrir padrões onde não há rótulo

## O que é aprendizado por reforço?

É quando um agente aprende a tomar decisões por tentativa e

erro, recebendo recompensas

É quando um agente aprende a tomar decisões por tentativa e erro, recebendo recompensas ou punições a cada ação ou punições a cada ação

tempo, vencer um jog

Ao longo do tempo, o modelo descobre quais sequências de ações maximizam a recompensa total (por exemplo: aumentar lucro, reduzir tempo, vencer um jogo)

Reforço = aprender jogando o jogo, não só olhando o histórico

## Forças e limites do reforço

<!-- image -->

sequencial, ações

1. Adequado para problemas de decisão sequencial, ações que afetam o futuro
2. 2.Aprende diretamente comportamentos a partir de interação com simulação ou ambiente real
3. Encontra políticas não triviais que otimizam custos ou tempo
4. Requer grande número de interações para aprender boas políticas
5. Necessita de definição cuidadosa da função de recompensa
